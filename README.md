# Bizarro Dune Dashboards

**Dune** is a blockchain data analytics platform that lets you query on-chain data using SQL and build interactive dashboards.  
This repository highlights two dashboards focused on Ethereum and DMT analytics.

---

## ETH Dashboard  
A dashboard tracking Ethereum price, market cap, staking distribution, inflation rate, and other key metrics.
